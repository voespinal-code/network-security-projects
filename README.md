# Network & Security Projects

Documentación de proyectos de ingeniería de redes y ciberseguridad reproducidos en laboratorio (GNS3 / Proxmox).

Cada proyecto se publica por fases: levantamiento AS-IS, diseño, implementación, pruebas y cierre.

> Los escenarios son ficticios y tienen fines formativos y de portafolio.
